## 2 傅里叶变换的性质

### 1）原理或实现流程（简要）

- **幅度显示**：直接显示 `|F|` 动态范围极大，细节看不清，故用 `log(1+|F|)` 压缩动态范围便于观察。
- **fftshift**：将零频（直流）移到频谱中心，便于与空域几何直观对应。
- **实现步骤**：
  1. 用 `BWBand` 生成矩形条带二值图。
  2. **任务1**：对同一图像分别计算未 shift / 已 shift 的幅度谱；对比 `|F|` 与 `log(1+|F|)`。
  3. **任务2**：比较 `BWBand(21,31)` 与 `BWBand(21,61)` 的功率谱（本 notebook 用 `fft_spectrum` 返回的 `log_mag` 作显示）；将 `BWBand(21,31)` 旋转 30° 后再算谱，与旋转前对比（验证旋转定理在可视化上的表现）。

### 2）代码、运行结果截图

**公共函数（Cell 0，节选）**：`BWBand`、`fft_spectrum`、`normalize_u8`、`rotate_image`、`show_and_save`。

```python
def fft_spectrum(gray):
    f = np.fft.fft2(gray.astype(np.float64))
    fshift = np.fft.fftshift(f)
    mag = np.abs(fshift)
    log_mag = np.log1p(mag)
    return f, fshift, mag, log_mag
```

## 3 使用功率谱、相位谱复原空域图像

### 1）原理或实现流程（简要）

- 对灰度图做 `fft2` 得复频谱 `F`；幅度 `|F|`、相位 `angle(F)`。
- **幅度主导重建**：`ifft2(|F|·e^{j0})`（相位置零）。
- **相位主导重建**：`ifft2(e^{j·angle(F)})`（幅度置 1）。
- **补充**：按作业要求计算 `I2 = ifft2(phase)`（此处 `phase` 为相位角矩阵，与上式「单位幅度」重建不同，用于对比观察）。

**步骤**：读入自己的灰度图 → `fft2` → 取 `mag`、`phase` → 三种 `ifft2` 组合 → `np.real` 取实部并归一化显示 → 与 `log+fftshift` 的幅度谱、相位角图同屏保存。

### 2）代码、运行结果截图

### 3）遇到的问题以及解决方法

| 问题 | 处理 |
|------|------|
| `ifft2` 输出为复数，`imshow` 异常或显示不对 | 取 `np.real(...)`，必要时 `normalize_u8` 映射到 0–255。 |

## 4 截止频率对滤波效果的影响

### 1）原理或实现流程（简要）

- 对测试图加 **椒盐噪声** 破坏空域像素。
- 构造 **高斯低通** `H(u,v)=exp(-D²/(2D0²))`，其中 `D` 为到频谱中心的距离（与 `fftshift` 后布局一致）。
- **步骤**：读 `Fig0333` → `add_salt_pepper_noise` → 对多个 `D0`（如 15、30、60）生成 `H` → `F·H` → `ifft2` 得滤波图像；同时保存滤波后频谱的 `log` 显示以便对比截止范围。

### 2）代码、运行结果截图

**相关函数（Cell 0）**：`gaussian_lowpass_filter`、`apply_frequency_filter`、`add_salt_pepper_noise`。

```python
def gaussian_lowpass_filter(shape, d0):
    m, n = shape
    y = np.arange(m, dtype=np.float64)[:, None] - m / 2.0
    x = np.arange(n, dtype=np.float64)[None, :] - n / 2.0
    d2 = x * x + y * y
    return np.exp(-d2 / (2.0 * (d0 ** 2)))

def apply_frequency_filter(img, h_filter):
    f = np.fft.fft2(img.astype(np.float64))
    fshift = np.fft.fftshift(f)
    gshift = fshift * h_filter
    g = np.fft.ifft2(np.fft.ifftshift(gshift))
    return normalize_u8(np.real(g)), normalize_u8(np.log1p(np.abs(gshift)))
```

### 3）遇到的问题以及解决方法

| 问题 | 处理 |
|------|------|
| 椒盐噪声经低通后仍有亮点/糊成一团 | 低通主要抑高频，椒盐是宽频干扰；增大 `D0` 会保留更多高频（含噪声），减小 `D0` 更糊但更平滑，需在报告中对比说明。 |
| 频域距离网格与 `fftshift` 不对齐导致滤波偏移 | `gaussian_lowpass_filter` 以图像中心为原点，与 `fftshift` 后零频在中心一致。 |

## 5 去除周期噪声（选做）

### 1）原理或实现流程（简要）

- 周期噪声在频域呈 **对称尖峰**；在 `log(1+|Fshift|)` 上找峰，用 **陷波（频域乘 0/1 掩膜）** 抑制尖峰再 `ifft2`。
